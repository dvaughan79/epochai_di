# AI News Analysis
- This repo contains data and code for **Epoch AI's assessment process**
- It includes the following files:
  - `smol_ai_analysis.ipynb`: Notebook with some dataviz for the assessment
  - `utils.py`: Python script with the functions used in the analysis
  - `smol-ai-news_may1.csv`: dataset used for the analysis
 

Notes about the data:
1. The data was collected from the amazing news aggregator [AI News](https://news.smol.ai/) (big thanks for their work!)
2. Granularity: day
3. Data collected:
   - [Tags](https://news.smol.ai/tags): Models, topics, people
   - Summary for each day
